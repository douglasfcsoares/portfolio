# Portfólio Front-end

Bem-vindo ao meu repositório de portfólio! Este projeto foi desenvolvido para mostrar minhas habilidades como desenvolvedor frontend, utilizando as mais recentes tecnologias e ferramentas do ecossistema JavaScript.

## Tecnologias Utilizadas

- **React:** Biblioteca JavaScript para construir interfaces de usuário.
- **Next.js:** Framework React para aplicações web com renderização do lado do servidor e geração de sites estáticos.
- **Tailwind CSS:** Framework CSS utilitário para estilização rápida e responsiva.
- **Shadcn:** Biblioteca de componentes que facilita a criação de interfaces modernas e acessíveis.
- **Framer Motion:** Biblioteca para animações em React, permitindo transições fluidas e interações dinâmicas.

## Funcionalidades

- Design Responsivo: O portfólio é totalmente responsivo, garantindo uma ótima experiência em dispositivos móveis e desktops.
- **Animações Interativas:** Utilizando Framer Motion, o portfólio apresenta animações suaves que melhoram a experiência do usuário.
- **Componentes Reutilizáveis:** Com Shadcn e Tailwind CSS, criei componentes estilizados e reutilizáveis que podem ser facilmente adaptados para diferentes seções do portfólio.
- **Navegação Intuitiva:** A estrutura de navegação foi projetada para ser simples e intuitiva, facilitando a exploração do conteúdo.
